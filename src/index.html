Syntax Tree Plus — Help

Edit the tree with the toolbar / keyboard, or type labelled bracket notation in the right-hand pane. Both stay in sync.

Notation

  • [S [NP the cat] [VP slept]] — brackets nest structure.
  • Unclosed brackets are auto-closed as you type.
  • Select text and press [ to wrap it in brackets.
  • [NP the big cat] — a multi-word terminal draws a triangle.
  • NP_1 — _ adds a subscript (co-index).
  • X^0 — ^ adds a superscript.
  • Two nodes with the same subscript are linked by a movement arrow when one is a trace (t, t*, e).

Inserting & moving

  • Insert in the middle: select the node that should come after your new one and use + Sib ◀ (before), or select the one before it and use + Sib ▶ (after).
  • Paste drops the copied subtree in as the last child of the selection. Paste ◀ / Paste ▶ place it as a sibling before / after the selection — so to paste into the middle, select the node it should sit next to and use ◀ or ▶ (exactly like the insert buttons).
  • ✥ Move mode: toggle it on, then drag any node onto another to re-parent it. A caret shows exactly where it will land among the target's children. You can't drop a node into itself.
  • ⤳ Arrow mode: toggle it on, click a node (the source), then click a second node (the target) to link them with a movement arrow. Click the source again, or click empty space, to cancel.
  • Templates: X-bar, CP/TP, and Coord expand the selected node into a standard skeleton (X-bar: Spec/X'/Compl; CP/TP: a full clause spine; Coord: &P with two conjuncts around a coordinator).

Tip: when renaming, type the full token including scripts, e.g. DP_1 or C^0.

Settings

Auto-subscript numbers repeated non-terminal node labels (NP → NP₁, NP₂) for display only — it isn't written into the bracket notation. Terminals (words) and nodes you've subscripted yourself are left as-is.

Select a node in the tree to give it a custom color.
