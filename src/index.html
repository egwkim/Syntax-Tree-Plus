Syntax Tree Plus — Help

Edit the tree with the toolbar / keyboard, or type labelled bracket notation in the right-hand pane. Both stay in sync.

Notation

  • [S [NP the cat] [VP slept]] — brackets nest structure.
  • Write several trees one after another — [S …] [S …] — and they're all drawn on the canvas.
  • Unclosed brackets are auto-closed as you type.
  • Select text and press [ to wrap it in brackets.
  • [N cat] is N over the word cat (italic); [NP [N]] is a bare node — a category or symbol with nothing under it. Brackets are what tell them apart, so use + Text for a word, + Child for a node, or Word/Node to flip a leaf.
  • [NP the big cat] — a multi-word terminal draws a triangle.
  • NP_1 — _ adds a subscript (co-index).
  • X^0 — ^ adds a superscript.
  • [NP the big cat_1] — scripts attach to the whole span, so a triangle can carry a movement index.
  • [NP "the" "cat"] — quote each word to keep two terminals separate; [NP the cat] is one span covering both.
  • "…" makes everything inside literal, so a label can contain a space, _, ^ or a bracket: [N "a_b"], ["my node" x]. There is no backslash escape (matching jsSyntaxTree).
  • [DP t -> 1] — -> draws a movement arrow to terminal column 1 (terminals counted left to right). <- points the other way, <> both ways. Arrows go on terminals, and the number needs a space in front of it.
  • A subscript is only a label: John_1 … his_1 draws no arrow. Say arrows with ->.

Keyboard

Remappable shortcuts can be changed in ⚙ Settings → Keyboard shortcuts.

Inserting & moving

  • Insert in the middle: select the node that should come after your new one and use + Sib ◀ (before), or select the one before it and use + Sib ▶ (after).
  • Paste drops the copied subtree in as the last child of the selection. Paste ◀ / Paste ▶ place it as a sibling before / after the selection — so to paste into the middle, select the node it should sit next to and use ◀ or ▶ (exactly like the insert buttons).
  • ✥ Move mode: toggle it on, then drag any node onto another to re-parent it. A caret shows exactly where it will land among the target's children. You can't drop a node into itself.
  • ⤳ Arrow mode: toggle it on, click a word (the source), then click a second word (the target) to draw a movement arrow. Picking the same pair again cycles the arrowheads (->, <-, <>, then off). Click the source again, or click empty space, to cancel.
  • Templates: X-bar, CP/TP, and Coord expand the selected node into a standard skeleton (X-bar: Spec/X'/Compl; CP/TP: a full clause spine; Coord: &P with two conjuncts around a coordinator).

Trees & view

  • Several trees in one tab: a tab holds a whole document, so it can carry more than one tree — useful for a set of examples that belong together, or a before/after pair. + Tree (Shift+T) adds one after the selected tree, Del Tree (Shift+D) removes it (undoable), and on a root node ← / → step between trees while Shift+←/→ reorder them. Every edit command applies to the tree you have selected; exports cover all of them. Choose side-by-side or stacked layout in ⚙ Settings.
  • Tabs: the bar under the toolbar holds several named documents. + adds one, ⧉ duplicates the current one, double-click a tab to rename it, and × closes it — with a Reopen button on the message that follows, so a close is never final. Drag a tab sideways to reorder it. Each tab keeps its own undo history.
  • Switching tabs: Ctrl+1…9 jumps straight to one (9 = last), and Ctrl+Alt+←/→ steps through them. Both work while you're typing in the text pane.
  • Half-finished text is kept: if what's in the text pane doesn't parse yet, the tab holds on to it (marked with a •) instead of discarding it when you switch away — the tree on the canvas stays at the last version that parsed.
  • On a phone: the toolbar collapses to a row of category chips — Insert, Edit, Clipboard, Templates, Tools, View. Tap one to show just those buttons; tap it again to hide the row and give the screen back to the tree. Undo/redo and Export/Settings/Help stay put.
  • Zoom & pan: use the ＋ / － / Fit buttons (or + / - / 0 / f), Ctrl/⌘+scroll to zoom toward the pointer, and drag empty canvas to pan.
  • Export: ⭳ Export opens one dialog — pick PNG, SVG or LaTeX, then download or copy to the clipboard. PNG adds a scale and a transparent-background option; you can export the current tab, all of them, or a range like 1-3,5. Several tabs save as one file each, named after the tab; LaTeX can instead combine them into a single .tex.

Tip: when renaming, type the full token including scripts, e.g. DP_1 or C^0.

Settings

Multiple trees chooses how the trees of one tab are arranged on the canvas — left to right, or one under another.

Auto-subscript numbers repeated non-terminal node labels (NP → NP₁, NP₂) for display only — it isn't written into the bracket notation. Terminals (words) and nodes you've subscripted yourself are left as-is.

Select a node in the tree to give it a custom color.

Keyboard shortcuts

Click a key, then press the new one. Navigation keys (arrows, undo/redo, Esc) are fixed.
